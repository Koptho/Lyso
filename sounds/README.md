# Lydfiler

Legg ekte lydfiler her om du vil overstyre den innebygde lydmotoren.

## Struktur

- `phonemes/s.mp3`
- `phonemes/m.mp3`
- `phonemes/l.mp3`
- `phonemes/n.mp3`
- `phonemes/r.mp3`
- `phonemes/a.mp3`
- `phonemes/e.mp3`
- `phonemes/i.mp3`
- `phonemes/o.mp3`
- `syllables/so.mp3`
- `syllables/ma.mp3`
- `syllables/le.mp3`
- `syllables/ni.mp3`
- `syllables/ro.mp3`

Når alle tre lydfilene for ei runde finst, vil appen automatisk bruke dei i staden for syntetisk lyd.
